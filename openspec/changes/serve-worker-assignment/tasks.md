order; each is ticked with its red-then-green evidence in that pull request body. Group 9 holds the
live checks that can run only on merged main and need serve alone: they are marked `(post-merge)`

no live pre-merge task: the live smoke belongs to #1325.

output, then make it green and keep that output. Each test must go red when the check it covers is

wrong type, truncated) asserts that no upstream call was made and no proof was minted. No test makes
a live or paid call: the upstream is a recording fake transport.
