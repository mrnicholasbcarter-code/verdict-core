# Support Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Release Cadence

- **Patch releases** (0.1.x): As needed for security/bug fixes
- **Minor releases** (0.x.0): Every 6-8 weeks with new features
- **Major releases** (x.0.0): When breaking changes are necessary

## Support Levels

### Active Support (Current Release)
- Security patches
- Bug fixes
- New features
- Documentation updates

### Security-Only Support (Previous Release)
- Critical security patches only
- No new features
- No bug fixes unless security-related

### End of Life
- No support
- Upgrade recommended

## Reporting Issues

### Security Vulnerabilities
**Do not** report security issues in public issues.
Email: security@verdict.dev

### Bug Reports
Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml).

### Feature Requests
Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml).

## Response Times

| Severity | Target Response |
| -------- | --------------- |
| Critical (Security) | 24 hours |
| High (Data loss, downtime) | 48 hours |
| Medium (Feature broken) | 1 week |
| Low (Enhancement, docs) | Best effort |

## Getting Help

- **Documentation**: https://verdict.dev/docs
- **Discussions**: GitHub Discussions
- **Discord**: https://discord.gg/verdict
- **Email**: support@verdict.dev

## Deprecation Policy

- Features marked deprecated will be supported for at least 2 minor releases
- Migration guide provided for breaking changes
- Deprecation warnings in code and documentation

## Maintenance Windows

- Scheduled maintenance: First Sunday of each month, 02:00-04:00 UTC
- Emergency maintenance: As needed with 1-hour notice
