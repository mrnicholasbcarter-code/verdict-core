# Verdict Core

Verdict Core is a policy-gated, availability-aware control plane for AI execution. Its goal-to-receipt workflow selects eligible routes using current capacity evidence, runs verified work units, and writes a review-gated receipt.

## Start here

- [Source repository](https://github.com/mrnicholasbcarter-code/verdict-core)
- [Interview golden-path guide](../guides/interview-golden-path.md): prerequisites, `verdict orchestrate`, `verdict eligibility`, `verdict supervise`, `verdict watch`, and `verdict run-receipt`.
- [Fresh-clone certification](../proof/INTERVIEW_GOLDEN_PATH_CERTIFICATION.md): recorded test gates and live run IDs; this certifies the branch, not merged-main CI.
- [ADR-036](../adr/ADR-036-goal-to-receipt-orchestration.md): selection, recovery, review, receipt contracts and current limits.

Verdict owns eligibility and model selection. OmniRoute supplies inventory and transport, not routing policy. A completed run requires validated work, a passing integration barrier and an independent AI code review. A missing or failed gate yields `BLOCKED`.
