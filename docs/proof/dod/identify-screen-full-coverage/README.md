# identify-screen-full-coverage evidence

This bundle contains raw captures from the 06:00 scheduled screen run and its installed unit/timer state. The DoD evidence file is intentionally deferred until the next scheduled run at 12:00Z; that run and an independent re-read will provide the required fresh-run and parent-confirmation captures.

The redacted unit files replace only host-specific paths in the live unit files. The scheduled journal is retained unchanged.
